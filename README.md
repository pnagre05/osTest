Clarification: The program was tested and was able to run on giant.utdallas.edu, which is one of the three servers that were permitted to be used for this project.

How to run: 
1) Compile the program using the provided Makefile. Utilize the following command - "make".
2) If you want to delete the executable and clean up your workspace, run "make clean"
3) After you have run make, run the following command
./my-sum n m input_file output_file
m is the number of worker processes that are to be created, n is the total values in the input
4) An example command is ./my-sum 8 5 input.txt output.txt
